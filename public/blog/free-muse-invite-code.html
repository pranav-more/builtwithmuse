How to Get a Free Muse Invite Code

Muse runs on invite codes. One code unlocks a bonus of tokens for you and a matching bonus for the person who shared it. Here is where to get a code free, how to redeem it, and how to share your own.

September 2026 · 5 min read
Need a code?

1. What an invite code actually gets you

An invite code is a short string that unlocks bonus Muse tokens. Tokens are what you spend to use Muse, and tokens from an invite code never expire, so a code is worth grabbing even if you are still setting things up.

According to Muse's current invite copy, both sides win when a code is redeemed: the referrer receives 1 billion Muse tokens and the new user receives 1 billion Muse tokens. There is also a deadline, so do not sit on a code. Redeem it in Settings within 48 hours of joining.

2. Where to get one free

The fastest source is the community pool on the Built with Muse homepage. Real users share real codes there, and each code shows how many open slots it has left. Pick one with room left and claim it.

Codes get claimed fast, so if the pool looks empty, check back in a little while. New codes land in the pool every day as more people join Muse and share their own.

One rule keeps you safe: never pay for an invite code. Codes are meant to be free, and the community gives them away. Anyone asking for money, your login details, or a favor in return is running a scam. Walk away and grab a code from the pool instead.

3. How to redeem your code

Redemption takes under a minute. Open the Muse app or go to muse.ai, open Settings, find the invite code field, paste your code, and confirm. Do this within 48 hours of joining, because the window is short.

If Muse has not launched in your country yet, sort out access first, then redeem. The full walkthrough is in how to use Meta Muse outside the US, which covers the laptop method, the iPhone method, and the waitlist in one place.

4. Share your own code and earn tokens

Once you are inside Muse, you get a referral code of your own. Every person who redeems it earns you a token bonus, so sharing is the easiest way to stack tokens without spending anything.

Add your code to the community pool so people who are actively looking can claim it. The complete walkthrough, including where to find your code in the app and how to share it well, is in how to find and share your Muse referral code.

5. Codes and offers to avoid

  • Paid codes. No legitimate code costs money. Sellers are scammers.
  • Codes from random direct messages. If you did not ask for it, do not trust it. Use the pool.
  • Token generators and hacks. There is no tool that creates tokens. These are phishing pages.
  • Anyone asking for your login. Redeeming a code never requires your password. Keep it private.
The short version Grab a free code from the community pool, redeem it in Settings within 48 hours of joining, then share your own code to keep earning tokens. Never pay for a code.
