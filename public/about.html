Need a code?

Get a code from the pool

Built with Muse is a community pool for Muse invite codes. People who are already inside Muse add the invite code they were given. People who want in take one, redeem it in the app, then add their own. Each code is handed to at most two people, the newest submissions go out first, and a code that two people flag as broken leaves the pool on its own. There is no sign in, no queue and nothing to pay.

Not Meta, not official

This is an independent project. It is not run by Meta, not affiliated with or endorsed by Meta, and not an official Muse channel. Muse, its invite system and the tokens it credits belong to Meta. This site only helps strangers pass codes to each other, and if Muse changes how invites work, the site will follow.

Who runs it

Two independent builders, Pranav More and Jayesh Marathe, moderate the pool: they retire broken codes, remove fakes and keep scrapers out. The code that runs the site is deliberately small, and the privacy page lists exactly what it stores.

Once you are in

This site's job ends when your code works. For what to do next, start with one real task such as turning a recipe reel into a grocery list, or browse the workflow community at Sundog, where people share what they actually build with Muse.
