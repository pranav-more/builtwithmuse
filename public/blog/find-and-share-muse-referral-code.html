How to Find and Share Your Muse Referral Code

Your Muse referral code is a token machine. Every person who redeems it earns a token bonus for both of you. Here is where to find your code in the app and how to share it so it actually gets claimed.

September 2026 · 5 min read
Need a code?

The community gives away free invite codes. Grab one, redeem it, then share your own.

Get a free code

1. Where your code lives

Open the Muse app and look for the invite or referral section. Your personal referral code and your full invite link both live there. Copy both: the code is what people paste into Settings, and the invite link is handy for sharing in messages.

Save the code somewhere you can reach quickly, like your notes app. You will be pasting it a lot.

2. Why sharing pays

According to Muse's current invite copy, every successful redemption earns both sides a bonus: the referrer receives 1 billion Muse tokens and the new user receives 1 billion Muse tokens. Share your code ten times and ten people redeem, and those bonuses stack. There is no easier way to grow your token balance.

The token mechanics behind all of this are in Muse tokens explained.

3. Share it in the community pool

The best place to share your code is the community pool on the Built with Muse homepage. Everyone there is actively looking for a code, which means your code gets claimed instead of sitting unseen. Add it through the share section, and it enters the rotation with its open slots tracked.

Codes with open slots get claimed first, so check back and keep your listing fresh. If your code runs out of slots, that means it worked.

4. Share it with friends directly

Friends are your highest converting audience. Send the code in a message along with one line of instruction: open the Muse app, go to Settings, paste the code, done. Mention the deadline too. They need to redeem it in Settings within 48 hours of joining, so tell them not to wait.

New to the whole code system? How to get a free Muse invite code covers redemption step by step.

5. Share it publicly, without spamming

Public sharing works when the code is welcome. Post it in threads where people are asking for Muse codes, in comments under Muse related posts, and in communities built around AI tools. One clear post beats ten scattered ones.

What not to do: drop your code in unrelated conversations, reply to every post with it, or pay to promote it. Spammy sharing gets ignored or removed, and it never converts as well as one well placed post.

The short version Find your code in the app's invite section, add it to the community pool, send it to friends with the 48 hour redeem note, and post it where codes are welcome. Every redemption earns both sides a token bonus.
