How to Gift a Muse Invite Code to a Friend

The best part of getting into Muse is bringing your friends with you. Gifting a code takes a minute, and when your friend redeems it, you both get the token bonus.

1. Get your own referral code

Before you can gift a code, you need one. Once you are inside Muse, you get a referral code of your own. It is yours to share, and every person who redeems it earns a token bonus for both of you. If you have not found yours yet, the walkthrough in how to find and share your Muse referral code shows where to look.

Need an invite code? Click here to grab one free from the community pool. Waiting on a launch in your country? Join the waitlist and we will send you a fresh code on launch day.

2. Send it to your friend

There is no ceremony to it. Text the code, drop it in a chat, read it out over a call, whatever matches how you two normally share things. Along with the code, tell them the two things that matter: install the Muse app, and redeem the code in Settings within 48 hours of joining. The second part is the one people forget, so say it twice.

3. What your friend needs to do

Your friend's side takes a few minutes. Install the app, sign in, then redeem your code in Settings within 48 hours of joining, according to Muse's current invite copy. That is the whole process. The most common mistake is saving the code for later and letting the window close, so nudge them to redeem right away.

4. You both get the bonus

Here is the part worth repeating: when your friend redeems your code, both of you receive 1 billion Muse tokens each, according to Muse's current invite copy. Not one side, both sides. Gifting a code is never a sacrifice. It is the fastest way to grow your own balance too.

5. Do not stop at one friend

One gifted code is a favor. A shared code is a system. Add your code to the community pool on this site's homepage so strangers can grab it, and mention it wherever people ask how to get into Muse. Every redeem earns the bonus again, for you and for them, and the bonuses stack up while you do nothing at all.

The short version Gifting a code means sharing your referral code and making sure your friend redeems it in Settings within 48 hours. Both of you receive the token bonus. The 48 hour window is what makes or breaks it, so redeem immediately, every time.

Frequently asked questions

How do I find my referral code?
It lives inside Muse once you are signed in. The sharing guide linked in this article walks through finding it.
What does my friend need besides the code?
Just the app and a few minutes: install Muse, sign in, and redeem the code in Settings within 48 hours of joining.
What if my friend misses the 48 hour window?
Do not risk finding out. The window is short, so the rule is simple: redeem the moment you join.
Is there a limit on how many people I can invite?
There is no limit we know of on sharing your code. Each redeem earns the token bonus for both sides.
Do I really get tokens for every friend who joins?
Yes. According to Muse's current invite copy, each redeem gives 1 billion Muse tokens to the referrer and 1 billion to the new user.
