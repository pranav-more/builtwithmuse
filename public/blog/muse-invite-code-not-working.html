Why is my Muse invite code not working?

Almost every failed Muse invite code comes down to a short list of causes, and each one has a different fix. That is why retrying the same code over and over rarely helps. If the cause is a typo, a careful retype fixes it. If the cause is a spent code, only a different code fixes it. If the cause is the clock, no code at all will fix that account, and your next move is a different one entirely. Work out which row below matches what you see, then jump to the matching section for the full check and fix.

  • The app says the code is invalid or not accepted. Likely cause: a typing error, an extra space carried in by copying, or a code that has already been spent. Fix: copy the code again, compare it character by character, and if a clean copy still fails, take a fresh code from the pool.
  • There is no redeem option in Settings at all. Likely cause: your account is older than 48 hours, or your app version hides the option in a different spot. Fix: update the app and look under Settings, then General, then Usage. If the account is past the window, the option is gone for that account.
  • The code worked for other people but fails for you. Likely cause: the code reached its use limit between their redeem and yours. Fix: take a fresh code, ideally one shared recently, and redeem it right away.
  • The code fails and you are outside a launched country. Likely cause: a region lock, not a broken code. Fix: a code cannot lift a region lock, so join the waitlist for your country and watch for launch news instead of burning codes.
  • The code was accepted but no bonus showed up. Likely cause: you are looking at the wrong account, or you already redeemed a code on this account. Fix: check your token balance on the same account you used to redeem, as described in check your Muse token balance.
  • A code you paid for fails. Likely cause: the code was already spent, fake, or never yours to use. Fix: never pay for a code. Codes are free, and the community pool exists so you never need a seller.

One note before you start: an invite code is a bonus, not a ticket into Muse. In a launched country you can join Muse without any code at all, and a code only adds the token bonus when you redeem it in time. According to Muse's current invite copy, the referrer receives 1 billion Muse tokens and the new user receives 1 billion Muse tokens when a code is redeemed. That bonus is what is at stake in this guide. Access itself is a separate question, and the region section below keeps the two apart.

Are you past the 48 hour redeem window?

This is the most common cause, and the least forgiving. According to Muse's current invite copy, you must redeem a code in Settings within 48 hours of joining. The clock starts when you create your account, not when you receive a code, not when you first open the app, and not when you get around to reading a message from a friend. Join on Monday morning and redeem on Monday evening and the timing is behind you forever. Join on Monday morning, forget about it, and try on Thursday, and you are past the window the invite copy describes.

Here is how to check. Think back to when you created your Muse account. If that was more than two days ago and you never redeemed a code, the window is the explanation, and no code will work on that account now. Users report that the redeem option itself disappears once the account is older than 48 hours, which is a useful tell: if you cannot find the option anywhere in Settings after updating the app, age is the likely reason. If you joined within the last two days, the window is still open, so move to the next section instead of assuming the worst.

The fix depends on which side of the line you are on. Inside the window, redeem right now, before you finish reading this guide, and confirm the bonus landed before you close the app. Outside the window, stop retrying codes on that account, because retries cannot reopen a closed window. Your bonus path from here is sharing your own code: once you are inside Muse you get a code of your own, and every friend who redeems it earns you the bonus, as explained in how to find and share your Muse referral code. Has the code already reached its use limit?

Every Muse code carries a limited number of redemptions, so a code that worked yesterday can be spent today. This hits public codes hardest. A code posted in a popular thread gets claimed fast, and by the time you copy it, the last slot may already be gone. The failure looks identical to a broken code, which is why people waste time retyping a code that was fine when it was posted and is simply finished now.

Be careful with exact numbers here, because Meta has not settled the limit in one place. The @Muse account said on 16 September 2026 to invite up to 20 friends, with 1 billion tokens to each side per redemption. The Meta AI account on Threads has said 20 to 30 depending on rollout. Some third party code lists claim a 30 use cap. Treat any single exact figure as the current copy rather than a promise, and focus on the shape that stays consistent everywhere: one code, a limited number of redemptions, and a bonus to each side for each redemption. That shape is also what our sharing guide reports, in how to find and share your Muse referral code.

The fix is a fresh code, not more attempts on the spent one. Retrying a spent code ten times does not free up a slot. Take a different code from the community pool, ideally one shared recently rather than one that has been circulating for weeks, and redeem it immediately. If you share codes yourself, the same logic applies in reverse: a code with open slots gets claimed first, so keep your listing fresh and tell every recipient about the 48 hour rule, or your code may sit unclaimed while its recipients drift past their windows.

Did you type the code with an error?

Typing errors are the most embarrassing cause and the easiest to rule out, so rule them out first. Muse codes are short strings where similar looking characters cause real trouble. The classic mix ups are the letter O read as the number zero, and the letter I read as the number one. An extra space at the start or the end, carried in when the code was copied from a message, is just as fatal. A missing character from a screenshot read too quickly finishes the job. Any one of these makes a good code look broken.

The fix is to copy and paste instead of typing. Copy the code from the original message, paste it into the redeem field, and check that no space has crept in at either end. If you must type it, type slowly and compare what you entered against the original character by character before you confirm. Reports differ on whether codes are case sensitive, so pasting also sidesteps that question entirely: a paste carries the exact characters, whatever the case rule turns out to be. If a clean paste still fails, you have ruled out typing, and the cause sits in another section of this guide.

One more typing trap: entering the code in a place that never submits it. That feels like a failed code, but the code was never tested at all. The next section covers where the code actually goes.

Did you enter the code in the wrong place?

Codes are redeemed in Settings, in the invite or redeem area, and nowhere else. Pasting a code into a chat box, a search bar, or a profile field does nothing, and it can convince you the code failed when it was never submitted. If nothing happens after you enter a code, check where you entered it before you declare the code dead.

The exact path depends on the surface you are on. In the app, look in Settings for the invite or redeem area, where some versions label it Redeem token. On the web at muse.ai, users report the path as Settings, then General, then Usage, labelled Redeem invite code. The exact spot moves between app updates, so look for the words invite, redeem, or referral rather than following an old screenshot. If you cannot find the option at all on a young account, update the app first, because some early builds did not show it in the same place.

When you find the right field, paste the code, confirm, and then check that the bonus landed before you close Settings. Entering the code but closing the app before confirming, or typing it somewhere else in the app, does not count as redeemed. Is Muse available where you are?

A code does not move your region. This is the cause people argue with most, because it feels unfair: you hold a working code, yet the app still will not let you in. But the code was never a region pass. It skips a queue and pays a token bonus in places where Muse has launched. It does not open the app in a place where Muse has not launched. If you are outside a launched country, the failure is a rollout limit, not a broken code, and no code will change that.

Meta's own Help Center says the Muse app and website are not yet available everywhere, and it does not publish a single country list, which is why guides disagree about the edges. The firm ground is this: Muse launched in the United States on 8 September 2026, Canada followed, and Japan joined on 23 October 2026 with Singapore on 28 October 2026, according to Meta's regional announcements. If you live outside the launched countries, your move is the waitlist for your country, not another code. Our country guides, starting with Muse available countries and how to use Meta Muse outside the US, track this rollout.

Do not confuse two different messages. "You are on the waitlist" is an access message: Muse has not opened for you yet. "Code invalid" is a code message: something about the code, the clock, or the account failed. If you see the waitlist message, stop testing codes and check availability instead. And be wary of anyone selling a region workaround as a fix: Meta's subscription rules say you must be located in a country where Muse is available, so misrepresenting your location risks your account rather than fixing your code.

Have you already redeemed a code on this account?

The invite bonus is a one time bonus for a new account. If you already redeemed a code on this account, a second code will not add a second bonus, and the app may reject it or simply show nothing new. This catches people who join, redeem a friend's code, forget they did it, and then try another code from a thread weeks later expecting a fresh payout.

Check before you try again. Open your token balance on the same account you used to redeem, and look for the bonus there. If the bonus is present, your code worked, and the second code is the non event, not the first one. If you redeemed on a different Meta account by mistake, the bonus sits on that account, not this one, so sign in to the account you actually used. A message that says a code was already redeemed can also mean the code itself was already claimed by someone else, which points back to the use limit section: take a fresh code and redeem it on an account that has not yet had its bonus.

The same logic covers the "already registered" trap. The bonus only works for a brand new Muse account inside its first 48 hours. An older account, or an account created long ago for another Meta product and only now opened in Muse, may already be past the point where a code can pay out. Age is measured from joining Muse, so if in doubt, the 48 hour section above is your check.

Is your account eligible at all?

A few account level blocks look exactly like code failures. Muse is for adults aged 18 or older, under its terms as reported across guides, so an age check that fails will stop you before any code can help. Make sure the birth date you entered is correct, and retry in the app if the browser flow failed, or the other way around. A Meta account problem, such as signing in with an account that cannot complete signup, also blocks redemption even when the code is perfect.

Another eligibility mix up is the waitlist itself. During the early rollout, some signups landed in a queue while access widened by country and account. If your account is still queued, a code is not the missing piece: access is. Wait for the queue to clear, then redeem within 48 hours of joining once you are actually in. And if your account was locked or restricted for another reason, a code cannot unlock it; our guide to Muse account locked covers that separate problem.

The practical test is simple. Can you sign in, use Muse, and reach Settings? If yes, your account is eligible and the failure is about the code, the clock, or the limit. If no, fix access first, because no code, fresh or otherwise, can pay out on an account that cannot get in.

Was the code sold to you, or does it look fake?

Never pay for a Muse invite code. Codes are free, they come from existing users passing on what the app gave them, and the community pool exists precisely so you never need a seller. A code you paid for carries every risk at once: it may already be spent, it may never have existed, and the seller has no way to make Meta accept it. If a paid code fails, the money is gone and the code was never the fix.

Watch for the same warning signs that mark any access scam. A page that pressures you to act immediately, promises a working code for everyone, asks for your password or a login verification code, or charges a fee to reveal or reserve a code is not selling access. A real code check happens inside the official sign in flow and the Settings redeem field, and nobody legitimate needs your password to hand you a code. If you already paid, stop there. Do not pay a second seller to fix the first one. Take a free code from the pool, redeem it inside your first 48 hours, and treat the paid code as a lesson, not a starting point for another purchase.

How do I get a fresh code that works?

Start at the community pool on the Built with Muse homepage, where members share codes that other people are actively looking for. Pick a code shared recently, because a fresh listing is more likely to have open slots than one that has been circulating for weeks. Then redeem it immediately, in Settings, inside your first 48 hours of joining, and confirm the bonus landed before you close the app. That sequence, fresh code plus immediate redeem plus confirmation, is the whole method.

If you are still waiting on a launch in your country, join the waitlist from the homepage instead, and we will send you a fresh code on launch day. Do not stockpile codes while you wait: a code saved for later is a code drifting toward a deadline, and the 48 hour clock runs from joining, not from the day you happen to open the message. If you share codes, pass the timing rule along with the code. Send three things: the code itself, where to redeem it, and the 48 hour deadline. A code forwarded without that warning often sits unread for days, and by the time your friend opens it, the window is gone. One extra line saves the code.

What is still unknown about invite codes?

Honesty matters here, because several guides state guesses as facts. Meta has not published the exact rejection wording, so do not memorize a specific message; the signal to watch for is simply that a correctly entered code in the right place was not accepted. Meta has not published how long a code stays valid before it is first used, or whether codes issued long ago keep working. Meta has not published whether the 48 hour window has any exceptions. And as the use limit section shows, Meta has not settled the exact redemption cap in one place.

That is why this guide sticks to what the live invite copy and Meta's public posts actually say, and treats everything else as practical advice from user reports. If Meta updates the invite flow, the documented rules are the thing to recheck first: the 48 hour window, the redeem path in Settings, and the launched countries. Until then, redeem within 48 hours of joining, paste instead of typing, take a fresh code when one fails, and you are on the safest ground available.

Still stuck after working through every section? Note exactly what you see: the message wording, when you joined, where you entered the code, and whether a fresh code failed the same way. That note is what support, and any helper you ask, needs to tell a clock problem from a limit problem from a region problem. Guessing without it just burns more codes.

Frequently asked questions

Why is my Muse invite code not working?
The usual causes are a missed 48 hour redeem window, a code that has already reached its use limit, a typing error, or a region lock where Muse has not launched. Check when you joined, paste the code again in the right Settings field, and if a clean copy still fails, take a fresh code from the community pool.
How long do I have to redeem a Muse invite code?
You must redeem a code in Settings within 48 hours of joining, according to Muse's current invite copy. The clock runs from account creation, not from the day you receive the code. Once the bonus lands, the tokens themselves carry no expiry, so redeem early and spend later.
What does it mean when a code has no uses left?
Every code carries a limited number of redemptions, and a code posted publicly gets claimed fast. Meta's public posts differ on the exact cap, with the @Muse account saying up to 20 friends and the Meta AI account on Threads saying 20 to 30 depending on rollout. A spent code cannot be revived, so take a different, recently shared code.
Can I use a Muse invite code in a country where Muse has not launched?
No. A code pays a token bonus and skips a queue in launched countries, but it does not lift a region lock. Meta's Help Center says the Muse app and website are not yet available everywhere, so if your country has not launched, join the waitlist and wait for launch news instead of testing codes.
Where do I enter a Muse invite code?
Enter it in Settings, in the invite or redeem area. In the app the option may read Redeem token, and on the web at muse.ai users report Settings, then General, then Usage, labelled Redeem invite code. Entering a code in a chat box, a search bar, or a profile field does nothing.
Can I try a second code if the first one fails?
Yes, if your account is still inside its first 48 hours and has not already redeemed a bonus. A second code is the right move when the first was mistyped or spent, because retrying a spent code cannot free up a slot. If you already redeemed once, a second code will not add a second bonus.
What should I do if I already missed the 48 hour window?
Stop retrying codes on that account, because no code can reopen a closed window. Your path to the bonus from here is sharing your own code, since every friend who redeems it earns you the bonus. Tell each recipient the 48 hour rule, so their codes do not meet the same fate.
